# Limitations and unsupported claims

1. **Unpaired evaluation composition.** Twelve canonical ID tasks and 80 RobotInit variant groups are different selections. The 67.17-point gap mixes any reset effect with task-composition and other uncontrolled differences. It is not a reset-only causal estimate.
2. **One policy, one recorded seed schedule.** No second backbone or independent seed-level replication supports a general statement about all VLA policies. Within-group episodes are not independent model replications.
3. **Missing physical reset traces.** All 920 principal records have null initial states and video references. Frozen label partitions are disjoint, but actual state/scene pairing and physical-state uniqueness cannot be reconstructed from labels alone.
4. **No completed failure taxonomy.** All 798 failed principal episodes are `UNLABELED`. Tracebacks explain software setup failures, not manipulation failure mechanisms. Horizon exhaustion is not a causal taxonomy.
5. **Training-data provenance unresolved.** The pinned converted dataset has 14,347 episodes, 2,238,036 frames and 40 base tasks, but the inspected episode metadata cannot certify the requested RobotInit variant membership. Training-selection code also expects a missing episode-level `task_index` and loses suite identity when passing bare IDs. No baseline or RISE training began under the recorded G2 attempt.
6. **Prototype methods unvalidated.** RISE model code, adapters, GroupDRO and checkpoint helpers exist, but unit tests or configuration files do not establish full-policy integration, learned performance or a useful mitigation. No final RISE checkpoint is included.
7. **Coverage and budget semantics.** All 1,550 manifest groups lack explicit base-task labels. Nominal pose-group budgets do not guarantee matched demonstration or frame budgets. Held-out method performance was not measured.
8. **Metric limits.** Worst-group and CVaR estimates use only ten episodes per group; zero observed success is not proof of zero true probability. Episode Wilson intervals ignore clustering. No confirmatory significance or multiple-comparison claim is made.
9. **Simulation and deployment.** No physical robot result, safety assurance, reposition-controller comparison, recovery study or deployment distribution assessment was completed.
10. **Reproduction boundary.** The public archive verifies saved evidence and lightweight software. It does not bundle licensed assets, datasets or policy weights; simulator replay and training are not revalidated. Historical runtime receipts cannot establish current compatibility. The full PyTorch-dependent suite is not claimed when those modules skip.
11. **Incomplete upstream investigation.** A prior metadata-only inspection found an `episode_metadata.file_path` field in the upstream RLDS schema. No verified conversion join to RobotInit variants was established. This archive does not claim that provenance is impossible in principle, and does not continue that investigation or download the dataset.

Unsupported: “RISE solves reset robustness,” “RISE is ineffective,” “all VLAs depend on one reset,” “67.17 points is the causal effect of reset,” “the full planned matrix completed,” or “unit tests reproduce GPU research.” None is a conclusion of this archive.
